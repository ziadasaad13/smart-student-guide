# Task 1: Smart Student Guide 🎓
### تاسك مقرر الذكاء الاصطناعي - كلية الذكاء الاصطناعي (جامعة كفر الشيخ)

نظام بايثون ذكي متكامل لمساعدة الطلاب في الاستعلام عن اللوائح الأكاديمية والمقررات وتحديد الأهلية للتسجيل استناداً إلى لائحة كلية الذكاء الاصطناعي بجامعة كفر الشيخ (برنامج عام 2023).

---

## 🚀 المميزات الرئيسية (Features)

1. **محرك استرجاع المعلومات (Information Retrieval - IR):**
   - فهرس معكوس (Inverted Index) مبني من الصفر.
   - حساب الأوزان باستخدام $TF \times IDF$ المنعم.
   - ترتيب النتائج باستخدام تشابه جيب التمام (Cosine Similarity).
   - دعم كامل للاستعلامات باللغتين العربية والإنجليزية مع معالجة وتوحيد النصوص.

2. **قاعدة المعرفة ومحرك الاستدلال (Knowledge Representation & Inference):**
   - تمثيل قواعد اللائحة ومتطلبات المقررات السابقة (Prerequisites).
   - محرك استدلال (Forward Chaining) يجيب على: *"ما هي المقررات التي يحق لي تسجيلها؟"*.
   - تحديد المستوى الدراسي (Levels 1 to 4) استناداً للساعات المجتازة.
   - فحص الحالة الأكاديمية والإنذارات (Academic Probation) والحدود المسموحة لساعات التسجيل (12 - 21 ساعة) طبقاً للـ CGPA والمادة (8) والمادة (22).
   - تتبع شجرة المسار التراكمي للمتطلبات (Prerequisite Lineage Tree).

3. **إدارة وتخزين الملفات (File Handling):**
   - ملفات نصوص **TXT**: نصوص اللائحة وتوصيف المقررات ودليل أعضاء هيئة التدريس والقاعات.
   - ملفات جداول **CSV**: جدول المقررات، جدول الدكاترة، جدول القاعات.
   - ملفات مهيكلة **JSON**: قاعدة المعرفة، والأسئلة الشائعة (FAQs)، وملفات الطلاب.
   - ملف سجلات **LOG**: ملف `data/queries.log` يسجل كافة الاستفسارات والعمليات مع التوقيت الزمني.

4. **واجهات الاستخدام (Interfaces):**
   - واجهة الطالب: إدخال البيانات، البحث الذكي، استدلال التسجيل، فحص مقرر، استعراض الأسئلة الشائعة.
   - واجهة الإدارة: استعراض وإضافة المقررات، رفع وتعديل وثائق اللائحة مع إعادة الفهرسة تلقائياً، وإضافة الأسئلة الشائعة، ومراجعة سجل العمليات.

## 💻 طريقة التشغيل (How to Run)

### 1. تشغيل واجهة النظام التفاعلية:
```bash
python main.py
```

### 2. تشغيل الاختبارات الشاملة والعينات التجريبية (Demo):
```bash
python main.py --demo
```

### 3. البحث المباشر في لوائح الكلية:
```bash
python main.py --search "مشروع التخرج"
python main.py --search "Deep learning neural networks"
```

### 4. فحص أهلية مقرر دراسي محدد:
```bash
python main.py --check "ML211"
```
