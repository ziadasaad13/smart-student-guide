# Smart Student Guide – دليل الطالب الذكي
كلية الذكاء الاصطناعي – جامعة كفر الشيخ (لائحة 2023، برنامج الذكاء الاصطناعي)

## التشغيل
```
python main.py          # البرنامج (Student / Admin)  | كلمة مرور الأدمن: admin123 (في config.py)
python demo.py          # sample runs للتقرير (sample_run.txt)
python tests/test_all.py
```
بايثون 3.8+ بدون أي مكتبات خارجية (TF-IDF وcosine مكتوبين يدويا). يفضّل VS Code terminal أو Windows Terminal لعرض العربي.

## الملفات
| ملف | الدور |
|---|---|
| search_engine.py | IR: tokenizer عربي/إنجليزي، inverted index، TF-IDF، cosine |
| knowledge_base.py | KR: حقائق (courses.csv) + قواعد (rules.json) + استنتاج + شرح الأسباب |
| file_manager.py | TXT / CSV / JSON + الـ log |
| context.py | تحميل كل الداتا وإعادة بناء الـ index بعد أي تعديل |
| student.py / admin.py / main.py | واجهات الطالب والأدمن والقائمة الرئيسية |
| data/courses.csv | 63 مقرر من الخطة الدراسية (مستويات 1-4) |
| data/schedule.csv, staff.csv | جدول المستوى 2 فصل أول 2026-2027 + الدكاترة والمعيدين |
| data/rules.json | أرقام اللائحة (144 ساعة، حدود التسجيل، المستويات، الإنذار، الدرجات) |
| data/docs/*.txt | 19 مستند للائحة (مقسمة بالمواد) + 63 وصف مقرر |
| logs/query_log.txt | يتسجل فيه كل سؤال وعملية |

## قواعد الاستنتاج
R1 لم يجتز المقرر | R2 اجتاز كل المتطلبات | R3 حد أدنى للساعات المجتازة (المشروع 100) | R4 الفصل المطروح فيه
R5 أقصى ساعات حسب CGPA (21/18/15/12، مستجد 18، صيفي 9، خريج 21) | R6 المستوى من الساعات (30/65/100)
R7 إنذار أكاديمي وخطر الفصل (4 متتالية/6 متفرقة) | R8 شروط التخرج ومرتبة الشرف | + حاسبة المعدل وحاسبة الغياب (20%/25%)

## ⚠ نقاط في اللائحة لازم تتأكدوا منها مع الكلية
1. مجموع ساعات الخطة (139 + التدريب) لا يساوي 144 تماما؛ والتدريب ساعتان في الخطة و4 في مادة 19. الرقم 144 محفوظ في rules.json وتقدروا تعدلوه.
2. مشروع (ب) مكتوب في الخطة بنفس كود مشروع (أ) (GP411)؛ استخدمنا GP421 ومتطلبه GP411 (افتراضنا).
3. متطلب RB411: الخطة تقول ML311 والتوصيف يقول BC311؛ اعتمدنا الخطة.
4. وصف ES421 في اللائحة منقول من مجال العمارة؛ أخذنا وصفا مختصرا مناسبا.
5. جدول المستوى 2 اتنقل من صورة؛ راجعوا القاعات والمواعيد مرة على الأصل.
6. الشغل بالـ prerequisites فقط: لم نطبق استثناء التسجيل بالتوازي (ضرورة قصوى) ولا الإضافي لـ "غير مكتمل".
